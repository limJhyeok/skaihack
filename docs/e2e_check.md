
## 소감 (실전 대비 유용성)

- 과제 내용이 현실적이다. 담당자(숙소 예약 관리자)가 일반적인 비개발자처럼 자기 요구사항을 명확히 인지하거나 설명하지 못하고 정립된 프로세스도 없어서, 개발자가 질문으로 요구사항을 끌어내야 하는 과정이 잘 녹아 있다.
- 인지 축 확인 문제가 소스 코드의 세부 내용까지 묻기 때문에, AI 에이전트에게 개발을 전부 맡기면 답할 수 없다. 묻고자 하는 바와 잘 맞는다.
