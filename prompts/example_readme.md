# 도서관 독서 모임 운영 도우미

## 상황

한빛 공공도서관은 매달 열 개가 넘는 주민 독서 모임을 운영합니다. 모임마다 진행자가 다르고, 참여자는 직장인부터 은퇴한 어르신까지 다양합니다. 모임이 끝나면 진행자는 그날 나온 이야기를 정리하고 다음 모임에서 다룰 질문을 준비해야 하지만, 대부분 자원봉사자라 이 일에 시간을 많이 쓰기 어렵습니다.

그래서 모임의 질이 진행자에 따라 크게 달라집니다. 어떤 모임은 매번 깊은 대화가 이어지지만, 어떤 모임은 책 줄거리만 확인하다 끝나고 참여자가 점점 줄어듭니다. 진행자가 혼자서도 모임을 돌아보고 다음 모임을 준비할 수 있는 방법이 필요합니다.

## 현업의 요청

평생교육팀의 첫 요청은 다음과 같습니다.

> "진행자분들이 모임이 끝난 뒤에 오늘 어땠는지 정리하고, 다음 모임 질문을 쉽게 준비할 수 있으면 좋겠어요. 제가 진행자 교육 때 강조하는 좋은 질문의 기준도 담기면 좋겠고요."

## 현업 파트너

과제 화면의 업무 대화 채널에는 평생교육팀 홍길동 사서가 연결되어 있습니다. 홍길동 사서는 독서 모임 진행자를 모집하고 교육해 온 현업 담당자로, 모임이 실제로 어떻게 운영되는지와 어떤 진행이 좋은지를 업무 경험을 바탕으로 이야기합니다.

다만 홍길동 사서는 개발자가 아닙니다. 어떤 API를 쓸지, 데이터를 어떻게 저장할지, 화면을 몇 개 만들지는 정해 주지 않습니다. 대화하며 문제를 이해하고 필요한 내용을 발견한 뒤, 구현할 수 있는 제품과 기술적 결정으로 바꿔 주세요. 이야기하는 모든 필요를 구현할 필요는 없습니다. 시간과 기술 조건을 고려해 범위를 정하고, 그 범위와 이유를 담당자와 명확하게 합의하는 것도 과제의 일부입니다.

## 과제

홍길동 사서와의 대화를 바탕으로, 독서 모임 진행자가 모임을 돌아보고 다음 모임을 준비할 수 있는 웹서비스를 기획하고 구현하세요. 무엇을 입력받고, 무엇을 분석하고, 결과를 어떤 형태로 보여 줄지는 정해져 있지 않습니다. OpenAI API를 어떻게 활용할지도 여러분의 판단에 맡깁니다. 진행자가 별도의 설명 없이도 편하게 쓸 수 있는 UI/UX도 함께 고민해 주세요.

## 실행 환경

결과물은 응시 환경 안에서 실행되는 웹서비스입니다. 브라우저 미리보기로 확인하려면 서버를 `0.0.0.0`에 바인딩하세요(외부 공개 금지). 공개 패키지는 설치할 수 있으며, 패키지는 가상환경에 설치하세요. 제출 때 실행 명령과 포트를 따로 입력하지 않으니 README에 실행 방법과 포트를 적어 주세요. OpenAI API는 `OPENAI_API_KEY`, `OPENAI_BASE_URL` 환경변수로 제공됩니다. 키를 코드에 직접 쓰거나 Git에 커밋하지 마세요.
