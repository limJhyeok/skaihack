# 공유 실험 장비 예약 관리

## 상황

미래바이오 연구소의 공용 장비실에는 원심분리기, 현미경, PCR 장비 등 스무 대가 넘는 장비가 있습니다. 지금은 장비마다 종이 예약표가 붙어 있고, 연구원들은 장비실까지 가서 빈 시간을 확인한 뒤 이름을 적습니다.

예약표가 장비마다 따로 있다 보니 같은 시간에 이름이 두 개 적히거나, 적어 놓고 오지 않는 일이 잦습니다. 장비 담당자는 누가 언제 장비를 썼는지 월말에 정리해야 하는데, 지워지고 덧쓴 예약표를 보며 하나씩 옮겨 적고 있습니다.

## 현업의 요청

장비운영팀의 첫 요청은 다음과 같습니다.

> "연구원들이 자리에서 장비 예약을 하고, 겹치거나 비는 일이 없었으면 좋겠어요. 장비마다 지켜야 하는 사용 규칙이 있는데 그것도 반영되면 좋겠고요."

## 현업 파트너

과제 화면의 업무 대화 채널에는 장비운영팀 홍길동 책임이 연결되어 있습니다. 홍길동 책임은 공용 장비의 관리와 사용 규칙을 맡아 온 현업 담당자로, 장비실이 실제로 어떻게 운영되는지를 업무 경험을 바탕으로 이야기합니다.

다만 홍길동 책임은 개발자가 아닙니다. 어떤 기술을 쓸지, 데이터를 어떻게 저장할지, 화면을 몇 개 만들지는 정해 주지 않습니다. 대화하며 문제를 이해하고 필요한 내용을 발견한 뒤, 구현할 수 있는 제품과 기술적 결정으로 바꿔 주세요. 이야기하는 모든 필요를 구현할 필요는 없습니다. 시간과 기술 조건을 고려해 범위를 정하고, 그 범위와 이유를 담당자와 명확하게 합의하는 것도 과제의 일부입니다.

## 과제

홍길동 책임과의 대화를 바탕으로, 연구원이 공용 장비를 예약하고 장비 담당자가 사용 현황을 관리할 수 있는 웹서비스를 기획하고 구현하세요. 데이터는 서버를 재시작해도 남아야 합니다. 그 밖의 구현 방식은 여러분의 판단에 맡깁니다. 연구원이 별도의 설명 없이도 편하게 쓸 수 있는 UI/UX도 함께 고민해 주세요.

## 업무 정책 (2026년 3월 개정)

### 1. 예약 단위와 운영 시간

1.1 예약은 30분 단위로 하며, 한 번에 최대 4시간까지 예약할 수 있습니다.
1.2 장비실 운영 시간은 평일 08:00~22:00입니다. 단, 장기 배양 장비(아래 표의 B등급)는 운영 시간 밖에도 예약할 수 있으며, 22:00 이후에 시작해 다음 날 끝나는 예약은 **시작한 날의 사용 기록**으로 집계합니다.

| 등급 | 장비 예 | 사전 교육 | 연속 예약 | 비고 |
|---|---|---|---|---|
| A | 원심분리기, 현미경 | 불필요 | 최대 4시간 | |
| B | 배양기, PCR | 필요 | 최대 48시간 | 사용 후 30분 세척 시간은 예약 시간에 포함하지 않음 |
| C | 질량분석기 | 필요 + 책임자 승인 | 최대 8시간 | 승인 전 예약은 '가예약'으로 표시 |

### 2. 예약 순서

2.1 같은 시간대는 먼저 신청한 사람에게 배정합니다.
2.2 한 연구원은 같은 장비를 하루에 두 번까지만 예약할 수 있습니다. 취소한 예약은 횟수에 넣지 않습니다.

## 데이터 명세

`data/equipment.csv`는 장비운영팀이 엑셀로 관리하던 장비 목록입니다.

| 열 | 형식 | 설명 |
|---|---|---|
| equip_code | 문자 | 장비 코드. 2025년 이전 코드(EQ-로 시작)가 일부 남아 있음 |
| grade | A/B/C | 위 등급표 기준 |
| status | 사용/점검/폐기 | 폐기 장비는 목록에서 빼지 않고 상태만 바꿔 왔음 |

## 예외 처리

- 장비가 점검에 들어가면 그 기간의 예약은 담당자가 연구원에게 개별 연락합니다.
- 사용 시작 15분이 지나도 사용 기록이 없으면 노쇼로 봅니다. 단, B등급 장비는 노쇼 판정을 하지 않습니다.

## 제약 사항

- 연구소 보안 규정상 연구원의 개인 휴대폰 번호는 시스템에 저장하지 않습니다. 연락은 사내 이메일 주소로만 합니다.
- 장비 사용 기록은 기존 월말 보고 양식(부록 B)의 열 순서 그대로 내려받을 수 있어야 합니다.

## 부록

### A. 용어
- **사용 기록**: 실제로 장비를 켠 시간이 아니라 예약된 시간을 기준으로 합니다.

### B. 월말 보고 양식 열 순서
날짜, 장비 코드, 연구원 사번, 시작, 종료, 사용 시간(분)
