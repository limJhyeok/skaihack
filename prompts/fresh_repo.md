[저장소 규칙]
- 스택: Python 3.12 + FastAPI + 바닐라 JS. 의존성은 fastapi, uvicorn, httpx, pytest만. requirements.txt에 이 이름만 적는다(버전 고정 없이).
- 파일 {{max_files}}개 이하, 코드(.py/.js/.html) 합계 {{max_lines}}줄 이하. 반드시 포함: README.md, CONTEXT.md, DECISIONS.md, requirements.txt, 서버 Python 모듈, static/index.html(작은 화면 하나), tests/ 아래 test_*.py 하나 이상.
- 모든 파일 경로는 저장소 루트 기준 상대 경로. 서버 앱 객체는 루트의 main.py에 `app`으로 둔다(`from main import app`으로 import 가능해야 함). 패키지 디렉터리를 쓰면 __init__.py를 넣는다.
- 저장은 메모리 또는 저장소 안 JSON 파일. 파일 경로는 모듈 상수로 두어 테스트가 바꿀 수 있게 한다. 데이터베이스 서버는 쓰지 않는다.
- 외부 모델 호출이 있으면 httpx로 OPENAI_BASE_URL의 /chat/completions를 부르는 함수 하나로 모으고, 그 함수를 바꿔 끼울 수 있게 한다. 키는 OPENAI_API_KEY 환경변수에서 읽는다. 테스트는 그 함수를 가짜로 바꾼다.
- 날짜·시각을 쓰면 "지금"을 돌려주는 함수 하나로 모아 테스트가 바꿀 수 있게 한다.
- README.md: 서비스 한 문단, 실행 명령(uvicorn, --host 0.0.0.0, 포트 명시), 테스트 명령.
- CONTEXT.md: 담당자와 합의한 요구 6~10개. 항목마다 출처를 "[담당자 확정]", "[작업자 결정]", "[AI 제안]" 중 하나로 표시한다. 결함이 어긴 요구가 여기 적혀 있어야 응시자가 "요구와 다르다"를 판단할 수 있다.
- DECISIONS.md: 설계 결정 3~5개와 이유.
- tests/: 주요 흐름을 확인하는 테스트 3~6개. 모두 통과해야 한다. 심은 결함은 테스트가 통과하는 상태로 숨어 있어야 한다(결함을 드러내는 상황은 테스트하지 않는다).
- 스타일은 AI 코딩 에이전트가 쓴 코드처럼: 보조 함수로 나누고, 방어 코드가 일부 있고, 주석은 적다.
- **금지**: 결함·미끼를 알려 주는 단서. 주석·문서·변수명에 "버그", "결함", "의도적", "TODO", "FIXME", "bug", "defect", "bait", "미끼", 결함 카탈로그 ID를 쓰지 않는다.
